# Quality checklist — follow-up-sweep

- [ ] All due/overdue commitments are listed, most-overdue first.
- [ ] Every active deal with no scheduled next step is flagged.
- [ ] Quiet-champion deals are flagged (or "none" stated).
- [ ] Items are ranked by priority: customer commitments → deals at risk → warm touches.
- [ ] Each item has exactly one concrete action.
- [ ] The list is capped (~7) with a "(N more below the cut)" line.
- [ ] Commitments without a date are surfaced, not silently dropped.

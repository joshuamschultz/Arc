# Quality checklist — assumption-audit

- [ ] Every active thesis appears exactly once.
- [ ] Each thesis lists the assumptions holding it up, or is flagged as having none.
- [ ] Every assumption is classified `holding`, `challenged`, `untested`, or `expired`.
- [ ] Assumptions with no falsification test are classified `untested`, not `holding`.
- [ ] Each classification names the evidence or the date behind it.
- [ ] Every at-risk thesis names the specific assumption that put it at risk.
- [ ] Each at-risk thesis has exactly one action: retest, revise, or retire.
- [ ] Newly contradicted assumptions were written back with `strategy_challenge`.
- [ ] The report leads with At risk, not with Holding.
- [ ] Nothing appears that is absent from the strategy cards.

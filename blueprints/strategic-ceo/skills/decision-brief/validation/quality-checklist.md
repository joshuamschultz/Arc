# Quality checklist — decision-brief

- [ ] The decision is stated as a choice between named, concrete options.
- [ ] Each option lists what would have to be true, as checkable conditions.
- [ ] The strongest case against the recommendation is written out, before the recommendation.
- [ ] Reversibility is classified, and the implication for pace is stated.
- [ ] Exactly one recommendation is named.
- [ ] The tradeoff the recommendation accepts is stated explicitly.
- [ ] A revisit trigger is named — a specific event or date, not "later".
- [ ] Every factual claim is grounded in a card or a named source.
- [ ] Unknown facts are marked `unknown`, never guessed.
- [ ] Sunk cost appears nowhere as a reason.

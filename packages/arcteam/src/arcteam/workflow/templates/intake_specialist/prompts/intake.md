# Intake

You received a request. Read the run input.

1. Pick the single best category for it.
2. Set a priority: low, normal, or high. Use high only when someone is blocked now.
3. Write a two sentence summary a busy person can act on.
4. List anything you would need to ask the requester before work can start.

Return only the JSON that matches the output schema. Do not invent facts that are not in the request.

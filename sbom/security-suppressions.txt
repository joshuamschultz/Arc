# Arc security suppressions — POA&M seed (Plan of Action & Milestones)
#
# This file is the single source of truth for vulnerabilities the CI security
# gate (`pip-audit` over the harness runtime closure) is permitted to accept.
# The gate reads the first whitespace-delimited token of every non-comment,
# non-blank line and passes it to `pip-audit --ignore-vuln`.
#
# Every entry MUST be annotated: vuln id · package · why deferred · compensating
# control · intended fix. Nothing lands here that can be safely bumped. Keep it
# truthful — auditors read this file as the POA&M of record (NIST 800-53 CA-5).
#
# Format:  <VULN_ID>   # <package version> · <why deferred> · <control> · <fix>
#
# The POA&M is currently EMPTY: the runtime closure has no accepted residual
# vulnerabilities. An empty file is the goal state, not an oversight — every
# finding is bumped rather than accepted. Note that a version cap is never a
# valid reason to accept a residual: FIPS posture comes from the linked OpenSSL
# provider, not from a Python package version, so capping a package buys no
# FIPS compatibility and only defers the next security fix.
